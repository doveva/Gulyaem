# Архитектура

Раздел описывает текущее устройство системы: границы модулей, потоки данных, интеграции и
нефункциональные требования. Это актуальное представление архитектуры, в отличие от ADR,
которые сохраняют историю отдельных решений.

Исходные продуктовые и geo-решения находятся в [`source_context`](../source_context/README.md).
Архитектурный контракт текущего этапа — в
[`Stage 3`](../stage%203/architecture-contract.md); принятые границы Stage 1 сохранены в
[`ADR-0007`](../adr/0007-street-segment-stage1-freeze.md) и
[`ADR-0008`](../adr/0008-coverage-parameters-stage1-freeze.md).

## Планируемые материалы

- обзор системы и контекстная диаграмма;
- карта логических модулей modular monolith;
- основные потоки данных;
- контракты внешних интеграций;
- требования к безопасности, наблюдаемости и производительности.
