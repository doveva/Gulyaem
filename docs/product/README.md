# Продукт

Раздел содержит актуальное описание продукта, его границ, пользовательских сценариев и
устойчивых доменных понятий.

Пока исходным материалом служит
[`gulyaem-project-context.md`](../source_context/gulyaem-project-context.md). По мере уточнения
продукта решения из исходного контекста переносятся сюда в более короткие тематические
документы; исходник при этом не переписывается задним числом.

## Что хранить в разделе

- product vision и границы продукта;
- ключевые пользовательские сценарии;
- глоссарий и устойчивую доменную модель;
- продуктовые ограничения и privacy expectations;
- ссылки на требования текущего Stage.
