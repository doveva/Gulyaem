# Технический долг

Здесь ведётся единый реестр осознанных компромиссов и проблем, которые нельзя безопасно
устранить в рамках текущего изменения.

## Правила реестра

- У каждой записи есть стабильный идентификатор `TD-NNN`.
- Формулируется наблюдаемая проблема, а не абстрактное пожелание «улучшить код».
- Указываются влияние, область, план устранения и условие приоритизации.
- Закрытые записи не удаляются: им ставится статус `Closed` и ссылка на изменение.
- Если долг относится к конкретному модулю, краткая ссылка также добавляется в README модуля.
