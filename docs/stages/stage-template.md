# Stage N — Название этапа

- **Status:** Draft
- **Goal:** проверяемый результат этапа
- **Owners:** ответственные
- **Started:** YYYY-MM-DD
- **Completed:** —

## Документы этапа

| Документ | Назначение |
|---|---|
| `stage-N-requirements.md` | Scope, сценарии, функциональные и нефункциональные требования |
| `architecture-contract.md` | Зафиксированные границы и допустимые направления зависимостей |
| `implementation-plan.md` | Последовательность реализации и проверяемые результаты |
| `acceptance-criteria.md` | Definition of Done и критерии приёмки |
| `open-decisions.md` | Решения, которые должен закрыть этап |

## Stage result

После завершения укажите фактический результат, ссылки на принятые ADR, известные отклонения и
созданный технический долг.
