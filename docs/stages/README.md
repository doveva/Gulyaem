# Этапы разработки

Каждый Stage получает отдельный каталог `docs/stage N/`. Каталог является самодостаточным
пакетом требований, решений, плана, критериев приёмки и фактических результатов этапа.

## Текущие этапы

| Этап | Статус | Документация |
|---|---|---|
| Stage 1 — Geo Exploration Playground | Draft | [`docs/stage 1/`](../stage%201/README.md) |

Общая последовательность Stage 0–9 описана в исходном
[`Development Stages`](../source_context/gulyaem-development-stages.md). Реализация конкретного
этапа опирается на его отдельный пакет, а не только на общий roadmap.

Для нового этапа скопируйте структуру из [`stage-template.md`](stage-template.md), замените `N`
и добавьте этап в таблицу выше.
