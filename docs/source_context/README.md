# Исходный контекст

Каталог хранит исходные продуктовые и архитектурные документы, сформированные до появления
рабочей структуры docs-as-code. Они служат контекстом и источником решений, но не заменяют
актуальные тематические разделы документации.

## Документы

- [`gulyaem-project-context.md`](gulyaem-project-context.md) — продуктовый контекст и сценарии.
- [`gulyaem-technical-design.md`](gulyaem-technical-design.md) — исходный технический дизайн.
- [`gulyaem-geo-exploration-adr.md`](gulyaem-geo-exploration-adr.md) — пакет ранних geo-решений.
- [`gulyaem-development-stages.md`](gulyaem-development-stages.md) — общий roadmap Stage 0–9.

Новые решения следует оформлять в актуальном разделе (`architecture`, `adr`, `product` или
`stage N`), а не дописывать в исходные документы без необходимости.
